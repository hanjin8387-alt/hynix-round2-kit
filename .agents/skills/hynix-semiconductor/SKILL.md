# 계산 전에 데이터의 의미 정하기

정리된 업무 요구와 실무자 답변을 재사용하고, 데이터 사전과 실제 값에서 계산에 필요한 정의를 보완한다. `행이 나타내는 대상 / 식별 키 / 관측 시점 / 검사 단계 / 단위 / 제외 조건` 중 미확정 항목만 질문으로 남긴다.

수율을 구하기 전에는 어떤 대상의 어떤 판정을 셀지 정한다. 재검사 기록을 제품 수에 합치거나 무조건 중복으로 버리지 않는다. 키 이름이 같아도 유일성 범위가 lot·wafer·검사 단계마다 다를 수 있다.

## 과제에 따라 선택

- 집계·결합: 분자와 분모를 같은 모집단으로 맞춘다. 조인 후 행이 늘어나 수량을 중복 합산하지 않는지 확인한다.
- 결함 조사: 결함 사건 수와 불량 개체 수를 구별한다. 장비별 비교에는 생산량·검사량의 차이도 반영한다.
- 센서 분석: 단위와 조건이 같은 계열을 시간순으로 다룬다. 관리한계 이탈을 제품 불합격이나 원인 확정으로 해석하지 않는다.
- 예측: 예측 시점에 이용 가능한 정보만 쓰고, 평가 목적에 맞게 시간·lot·wafer 겹침을 통제한다.

해당 계산이 필요할 때만 [계산 점검표](references/metrics.md)의 관련 절을 읽는다. 참고자료에 나온 예시는 실제 과제의 규격이나 기준값이 아니다.

## 결과에 붙일 정보

어떤 대상을 어느 기간·단위로 계산했는지, 제외한 자료와 그 이유, 작은 입력으로 대조한 결과, 해석의 한계를 함께 남긴다. 관찰한 차이와 추정 원인, 추가로 확인할 증거를 구분한다.

원본을 유지하면서 필요한 분석만 수행한다. 실제 설비 조작이나 공정 승인으로 확대하지 않는다.
