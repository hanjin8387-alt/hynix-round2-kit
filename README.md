# SK하이닉스 2차 예선 준비 키트

Sol 6.1·Luna 6·Terra 5.6이 함께 사용하는 공통 지침과 선택형 스킬 5개다. 응시 환경에 제공된 Codex에서 사용한다. 추가 MCP나 개인 API 키는 필요하지 않다.

## 시험장에서 한 번에 적용하기

**시험 웹 IDE에서 과제 폴더의 일반 터미널**에 아래 한 줄을 붙여넣는다. Codex 대화 입력창에 넣는 명령이 아니다.

```bash
bash -c 'set -e; k=$(mktemp -d); git clone -q --depth 1 https://github.com/hanjin8387-alt/hynix-round2-kit.git "$k"; bash "$k/start.sh" "$PWD"'
```

공개 저장소를 임시 폴더에 내려받고, 스킬 5개와 반도체 참고자료를 현재 과제 폴더의 `.agents/skills`에 추가한 뒤 Codex를 시작한다. `git`, Bash와 제공된 `codex` 명령을 사용하며 별도 패키지를 설치하지 않는다.

- 기존 과제 파일과 README는 변경하지 않는다.
- 기존 `AGENTS.md` 또는 `AGENTS.override.md`가 있으면 보존한다. 둘 다 없을 때만 새 `AGENTS.md`를 추가한다.
- 공통 지침은 Codex의 첫 요청에도 함께 전달한다. 기존 공식 과제 지침을 우선하고 설치 상태만 확인한 뒤 사용자 요청을 기다린다.
- 같은 내용의 스킬은 재사용한다. 내용이 다른 동명 스킬이나 설치 경로 충돌이 있으면 파일을 덮어쓰지 않고 중단한다.
- 모델·추론 강도·권한·전역 설정은 변경하지 않는다. 제공 환경의 신뢰·승인 안내가 나오면 정상 절차를 따른다.

Codex가 준비되면 `과제 안내를 읽고 시작해줘. 현재 과제 남은 시간은 ○○분이야.`라고 요청한다. 스킬 목록에 나타나지 않으면 `.agents/skills/hynix-triage/SKILL.md`처럼 파일을 직접 읽게 할 수 있다.

이 명령은 새 Codex 대화를 시작한다. 작업을 시작한 뒤에는 가능한 한 그 대화를 이어간다. 터미널을 다시 열어 새로 시작할 때는 같은 명령으로 재적용할 수 있고, 이전 작업 요약도 전달한다. 이미 진행 중인 Codex 대화 안에서는 이 셸 명령을 실행하지 않는다.

플랫폼의 다운로드나 실행 제한에 막히면 우회하지 말고 Cofa Helper 또는 문제 신고를 이용한다. 14:00은 서술형까지 포함한 전체 마감이며, 과제 타이머와 다르다.

## 진행하면서 쓰는 요청

| 상황 | Codex에 입력할 예시 |
| --- | --- |
| 과제 파악·요구 변경 | `$hynix-triage 필수 요구와 확인 질문을 정리해 줘.` |
| 구현 | `$hynix-build 정리된 요구를 사용해 핵심 기능부터 완성하고 확인해 줘.` |
| 실무자 답변 도착 | `실무자가 이렇게 답했어: … 기존 가정과 비교하고 영향받은 부분만 갱신해 줘.` |
| 제출 전 점검 | `$hynix-verify 성공한 검증은 재사용하고 필수 조건의 누락과 오류를 확인해 줘.` |
| 제출 전 읽기 복습 | `$hynix-explain 지금은 제출 확정 전이야. 중요한 결정과 검증 근거를 쉬운 말로 짧게 정리해 줘.` |
| 직접 설명 연습 | `$hynix-explain 제출 확정 전, 5분만 연습하자. 하나씩 질문하고 내 답을 듣고 점검해 줘.` |
| 실제 반도체 데이터 분석 | `$hynix-semiconductor 이 데이터의 집계 단위·분모·검사 이력을 확인해 줘.` |

다섯 스킬을 매번 순서대로 호출할 필요는 없다. 구현 중 확인한 결과는 제출 점검에서도 재사용한다. 반도체 스킬은 해당 과제에서만 사용한다.

## 시간과 제출

180분을 모두 사용할 수 있다면 다음처럼 나눌 수 있다. 고정 단계가 아니라 시작 예시이며 실제 남은 시간에 맞춰 줄인다.

- 처음 15분: 적용·요구 파악·중요 질문.
- 다음 110분: 핵심 구현과 변경 부분 확인, 실무자 답변 반영.
- 다음 30분: 필수 조건 점검과 오류 수정, 요구된 문서 정리.
- 다음 15분: 설명 복습과 저장 확인.
- 마지막 10분: 사용자가 제출 진행.

전체 마감에서 후속 6문항×5분과 질문 생성 대기·최종 처리 여유가 부족하면 구현을 더 일찍 마친다. 제출물 확정 이후에는 이 키트의 AI 사용을 중단한다. 복습은 질문 생성 대기 시간이 아니라 제출 확정 전에 끝낸다.

공개 준비 자료를 가져오는 Git Clone과 시험 작업을 외부로 올리는 Git Push는 다르다. 시험 중에는 문제·데이터·코드·결과물을 외부로 전송하거나 저장소에 올리지 않는다. 개인 PC의 비공개 파일 업로드도 사용하지 않는다.
